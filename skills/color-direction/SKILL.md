# Color direction

- Define a restrained dominant palette with one supporting accent when appropriate.
- Attach color words to specific objects, materials, light sources, or spatial layers.
- Use warm/cool, complementary, analogous, monochromatic, or split-complementary relationships deliberately.
- Preserve tonal separation so the focal subject remains readable.
- Use exact hex colors only when the user provides or requests them.
