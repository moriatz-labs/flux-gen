Documentation

Your first wallpaper, in three steps.

One install command, one guided setup, then describe the wallpaper you want in plain English.

Windowsirm https://flux-gen.moriatz.com/install.ps1.txt | iex
macOScurl -fsSL https://flux-gen.moriatz.com/install.sh | sh
  1. 01

    Install Flux

    Use the installer above, then open a new terminal.

    flux --version
  2. 02

    Run the guided setup

    Flux opens the right key pages, masks what you paste, stores keys in your operating system credential store, and lets you choose both models.

    flux setup
  3. 03

    Describe a wallpaper

    Flux saves it to Pictures/FluxGen and immediately applies it as your current wallpaper.

    flux "a quiet blue-hour coast"

Want to skip prompt enhancement? Run flux config enhancement and choose No. Then only a DEAPI key is required.
