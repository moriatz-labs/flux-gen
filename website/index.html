There are many image generators,
but this one makes wallpapers.

Describe the scene. Flux shapes the prompt, renders for your desktop, and saves the finished image.

$ curl -fsSL https://flux-gen.moriatz.com/install.sh | sh

Documentation

One command from idea to desktop.

flux <description>Generate and save a wallpaper
flux configSee models, output folder, and key status
flux config keySecurely add or change an API key
flux -pmChoose the prompt model
flux -imChoose the image model

Illustration

Abstract

Environment

Landscape, architecture, weather, and scale.

Color

Controlled palettes tied to light, objects, and depth.
