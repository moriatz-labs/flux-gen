Documentation

Your first wallpaper, in three steps.

  1. 01

    Install Flux

    Use the installer above, then open a new terminal.

    flux --version
  2. 02

    Run the guided setup

    Flux links to each provider, stores keys securely, and separately offers instant wallpaper application and folder rotation.

    flux setup
  3. 03

    Describe a wallpaper

    Flux saves it to Pictures/FluxGen, can apply it immediately, and can rotate the whole folder.

    flux "a quiet blue-hour coast"

Want to skip prompt enhancement? Run flux config enhancement and choose No. Then only a DEAPI key is required.
