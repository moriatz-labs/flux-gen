Documentation

Your first wallpaper, in four steps.

  1. 01

    Install Flux

    Use the installer above, then open a new terminal.

    flux --version
  2. 02

    Add your API keys

    Add DEAPI first. If prompt enhancement is on, add one prompt-provider key too.

    flux config key
  3. 03

    Choose your models

    Pick a prompt model, then choose from the live DEAPI image catalogue.

    flux -pm   flux -im
  4. 04

    Describe a wallpaper

    Flux generates it and saves the image to Pictures/FluxGen.

    flux "a quiet blue-hour coast"

Want to skip prompt enhancement? Run flux config enhancement and choose No. Then only a DEAPI key is required.
